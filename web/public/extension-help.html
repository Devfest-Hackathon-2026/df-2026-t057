Chrome拡張の導入・更新

現在は開発版を配布しています。Chrome Web Storeの掲載は準備中です。

  1. 運営から公開先向けの最新版の拡張フォルダーを受け取ります。
  2. Chromeの拡張機能の管理画面でデベロッパーモードを有効にし、「パッケージ化されていない拡張機能を読み込む」でフォルダーを選びます。
  3. 更新時は同じ拡張の「再読み込み」を押します。
  4. 拡張メニューの「Googleで接続・切替」で管理画面と同じアカウントを選びます。
  5. 管理画面を開き直し、設定の「接続を確認」を実行します。
  6. 拡張の「テスト通知を送る」を押し、OSの通知が見えることを確認します。

Googleへの接続が開けない場合、運営による拡張IDの許可設定が必要です。Chrome終了・スリープ中の通知はできません。
