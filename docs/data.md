## 1. 対象地域：熊本県宇城市

宇城市を対象にし、最初は松橋地区に絞って作る。

### 1.1 選んだ理由

1. **避難所ごとの収容人数が、市の公式資料で確かめられた。**
   - 「宇城市避難所一覧（令和8年6月現在）」に、避難所ごとの収容人数が載っている（2.1）。
   - 収容人数は割り当ての制約の中心で、これがないと最適化が成り立たない。
   - 国土地理院の避難所データにも収容人数の項目はなく、収容人数があるのはこの市の資料だけだった。ほかの候補地域では、収容人数のデータを確かめられなかった。
2. **災害の種類ごとに、使える避難所が分かる。**
   - 同じ一覧に、洪水・高潮・地震・津波のそれぞれで使えるか（○×）が載っている。
   - 「地震なら使えるが津波なら使えない避難所」を割り当ての制約にできる。災害の種類がまだ決まっていなくても、同じデータで対応できる。
3. **避難所が足りないことが、数字で示せる。**
   - 指定避難所の収容人数は合計 10,513人で、人口 57,032人の約18%。
   - 避難行動要支援者の名簿に載っている人は 6,902人いる。そのうち個別避難計画ができているのは 2,720人（39.4%）だけ（2.5）。
   - 「誰をどの避難所へ運ぶか」を事前に決めておく必要があることを、公的な数字で説明できる。
4. **今年の震度7の被災地で、避難の記録が残っている。**
   - 令和8年熊本地震（2026年7月28日）で、宇城市と氷川町が震度7を観測した。
   - 宇城市の避難者は、内閣府の速報で8月12日時点 4,098人。市も避難者数を毎日公表していた（2.6）。
   - 課題が実際に起きた場所なので、審査の「解決する課題が具体的かつ明確か」で説明しやすい。
   - 要件定義書 1.1 の背景（宇城市・氷川町で震度7）とそのままつながる。
5. **地区に分かれていて、絞り込める。**
   - 一覧は三角・不知火・松橋・小川・豊野の5地区に分かれている。5日間で市全体のデータをそろえるのは重いので、1地区から始める。
6. **要配慮者のためのデータが、公的にそろっている。**
   - 国土地理院のデータで、受け入れ対象が「要配慮者」の避難所（福祉避難所に当たる）が8か所分かる（2.2）。
   - 介護施設の位置が、厚労省のデータで分かる（2.3）。
   - 「施設からどの福祉避難所へ運ぶか」を、実在の施設と避難所の位置で組み立てられる。人はすべて架空にする。

### 1.2 最初の地区を松橋地区にする理由

- 5地区のうち避難所が最も多い（17か所、そのうち指定避難所15か所）。割り当ての選択肢が多く、最適化の効果が見えやすい。
- 要配慮者を受け入れる避難所8か所のうち5か所が松橋地区にある：
  - 松橋東支援学校、松橋支援学校、松橋西支援学校
  - 松橋西防災拠点センター、松橋東防災拠点センター
- 大字「松橋」だけで人口 5,638人、そのうち65歳以上が 1,393人（2.4）。
- 災害の種類によって、要配慮者の行き先が変わる。たとえば松橋支援学校は、要配慮者を受け入れる避難所だが、洪水・高潮・津波では使えない（2.1 の ○×）。市のハザードマップでも、高潮で 5.0m 以上浸水する区域にある（2.8）。災害の種類を変えると割り当てが変わる様子を、デモで見せられる。

### 1.3 捨てた案

| 地域 | 良い点 | 捨てた理由 |
|---|---|---|
| 益城町 | 平成28年熊本地震で、10か所の避難所に最大16,050人（町の人口の約半分）が避難した記録がある。震災記録誌もある | 避難所ごとの収容人数を確かめられなかった |
| 人吉市・球磨村 | 令和2年7月豪雨で、特別養護老人ホーム「千寿園」の入所者14人が犠牲になった。施設からの避難の課題として、国交省と厚労省の検討会の資料がある | 避難所ごとの収容人数を確かめられなかった。災害の種類が水害に限られる |
| 熊本市 | 二つの熊本地震の記録が多い | 市のオープンデータのサイトで避難所の一覧が見つからなかった。範囲が広すぎる |

人吉市・球磨村は「施設からの避難」の事例として強い。そのため、プロダクト説明ドキュメントの課題の根拠として引用することを考える。

### 1.4 弱点と対策

- **避難所一覧は PDF で、CSV ではない。** 52行なので、手で JSON に写す。緯度経度は国土地理院のデータ（2.2）から取り、そこにない避難所は住所から求める。
- **避難所一覧は地震の前（令和8年6月）の版。** 地震のあと受け入れを止めた避難所もある（例：8月14日、松橋西防災拠点センターが新しい避難者の受け入れを停止）。本システムは事前の計画づくりに使うものなので、平常時の一覧を使うことに問題はない。
- **収容人数は面積からの機械的な値。** 指定避難所は 3.5㎡に1人、指定緊急避難場所は 2㎡に1人で計算されている。実際に受け入れられる人数ではないので、画面で想定値であることを示す（NFR-010、要件定義書 11 章）。
- **熊本県の高潮浸水想定は、機械で読める形で手に入らない。** 国土数値情報に熊本県の高潮の分がない。市のハザードマップは画像だけの PDF で、WebGIS は無断での複製・転用を禁じている（2.8）。高潮は避難所一覧の ○× だけで扱い、地図に浸水区域は描かない。
- **「松橋地区」の範囲がデータごとに違う。** 避難所一覧の「松橋町」は旧松橋町で、大字松橋のほかに曲野、久具、豊福なども含む。e-Stat の小地域には旧町との対応がないので、どの大字を松橋地区に入れるかは自分たちで決める。

## 2. 中身を確かめたデータ

すべて 2026年11月5日に公式ページから取得し、ファイルを開いて確かめた。原資料の置き場所は 3 章。

### 2.1 宇城市避難所一覧（令和8年6月現在）

### 2.2 国土地理院 指定避難所・指定緊急避難場所データ（宇城市分）

- **出どころ**：国土地理院の指定緊急避難場所・指定避難所データ。宇城市の分を CSV と GeoJSON で取得
- **最終更新**：2025年1月23日
- **ライセンス**：国土地理院コンテンツ利用規約（PDL1.0）。出典の記載が必要で、加工した場合はその旨も書く

**指定避難所**（45件）

- 列：NO、共通ID、施設・場所名、住所、指定緊急避難場所との住所同一、その他市町村長が必要と認める事項、受入対象者、緯度、経度、備考
- 緯度経度がある。収容人数の列はない。
- 受入対象者が「要配慮者」の避難所が8件ある。共通ID の決まりでも福祉避難所に当たる。
  - 松橋地区：松橋東支援学校、松橋支援学校、松橋西支援学校、松橋西防災拠点センター、松橋東防災拠点センター
  - ほかの地区：三角防災拠点センター、不知火防災拠点センター、豊野防災拠点センター

**指定緊急避難場所**（48件）

- 列：施設・場所名、住所、緯度、経度など
- 災害の種類ごとの列がある：洪水、崖崩れ・土石流及び地滑り、高潮、地震、津波、大規模な火事、内水氾濫、火山現象。対応する災害には「1」が入る。

**2.1 との違い**

- 2.1 の市の一覧は52か所で、こちらより多い。三角中学校、三角B＆G海洋センター、旧豊野小学校などは、こちらに載っていない。
- 収容人数は 2.1 から、緯度経度と要配慮者の受け入れはこちらから取る。

### 2.4 e-Stat 令和2年国勢調査 小地域集計（熊本県）

- **出どころ**：e-Stat の令和2年国勢調査 小地域集計、「第3表 男女，年齢（5歳階級）別人口，平均年齢及び総年齢－町丁・字等」
- **ファイル**：熊本県の CSV が1つ。文字コードは cp932、見出しは5行目
- **ライセンス**：e-Stat 利用規約。商用利用可。出典の記載が必要で、加工した場合はその旨も書く
- **列**：市区町村コード、町丁字コード、大字・町名、字・丁目名、総数、5歳ごとの人口、（再掲）65歳以上、（再掲）75歳以上、（再掲）85歳以上、平均年齢など。男女別（総数・男・女）の行がある
- **宇城市**：市区町村コード 43213 で82行（男女=総数）。秘匿処理された行はない
  - 例：大字「松橋」は総数 5,638人、65歳以上 1,393人

**境界データ**

- e-Stat の統計GIS から、宇城市の小地域の境界を Shapefile で取得した（JGD2011、ポリゴン101件）。
- 属性の KEY_CODE が「市区町村コード＋町丁字コード」で、人口の CSV と結びつけられる。
- GeoJSON では配られていないので、使うときに変換する。

- 洪水・津波・高潮・内水・土砂災害・ため池を重ねた地図と、ため池ごとの地図がある。内水とため池は PDF にはなく、WebGIS にだけある。

- アプリでこの地図を表示したり加工したりはしない。浸水区域を地図に描くときは、国土数値情報（2.7）を使う。

## 3. 原資料の置き場所

取得した原資料は `docs/sources/` に置く。このフォルダは `.gitignore` に入れてあり、コミットしない。

- 合計で約330MBあり、大きい。
- 一部のデータは、再配布してよいかの条件を確かめていない。
- 提出用リポジトリは public になる。
