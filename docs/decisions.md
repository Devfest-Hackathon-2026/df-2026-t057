# 判断の記録（Own the Why）

審査テーマ「Own the Why, Build with Intent.」の材料です。決めたこと・比べた案・捨てた理由を、決めたその場で残します。

| 日付 | 決めたこと | 比べた案 | 選んだ理由 | 捨てた理由 |
|---|---|---|---|---|
| 11/4 | 災害ゲームをやめ、医療・福祉の「要配慮者の避難計画」にする | 3D の避難ゲーム（エンタメ） | 誰の課題かが具体的。実際の被災事例がある | ゲームは課題が弱く、カテゴリもずれる |
| 11/4 | 対象を「人の移送」＋「物資の需要予測」にする | 物資の配分だけ | 既存の熊本県の実証は物資のみで、人の移送は空白 | 物資だけでは既存の取り組みと重なる |
| 11/4 | 最適化は計算（Route Optimization / OR-Tools）、解釈と説明は Gemini に分ける | すべて Gemini に任せる | 経路・時間は決定的に計算したほうが正確で説明できる | LLM だけでは最適性も再現性も担保できない |
| 11/5 | 開発は private リポジトリ、提出は public リポジトリに最終版だけ移す | public の提出用リポジトリで直接開発 | 作業中の内容を公開しない。メンバーの招待を自分たちでできる | 提出用ではメンバー招待の権限がない |
