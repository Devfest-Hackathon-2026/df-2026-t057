# CIのテスト削減と単純化

本人の指示に合わせ、実行条件を増やす方式をやめ、通常のPR/mainでは関連するLint・型・単体テストとE2E2本だけを実行する。

- ログイン画面：個人データを取得しないこと、デモ復帰、狭い画面、ライト／ダークのaxe検査。
- 課題登録→作業→完了：主要操作と保存・報酬の結果。

全件E2EはRun workflowから手動実行する。通常変更を重要／非重要に分類して全件を選ぶ条件、変更したE2Eファイルの個別再実行、拡張専用スモークの分岐を削除した。通常CIの拡張ビルドも省き、全件実行時だけ行う。

## テスト自体の整理

CI/配信の91件を17件に統合した。設定の文字列・順序・パスごとに同じ条件を繰り返すテストを削除し、実際のジョブ選択、失敗・取消の停止、最新main、候補確認、イメージ不一致、切り戻しの検査を残した。

ログインE2Eの待機・設定失敗2件は、既存の認証・ログイン画面の単体テストと重複するため削除した。時刻・報酬・保存・認証の重要な単体テストは削除していない。詳細な画面・拡張E2Eは手動検査として維持する。

## マージ済み改善との分担

PR #50のGoキャッシュ分離、Goセットアップ先行、API/Web並列ビルド、Playwrightの3並列設定はそのまま維持する。高速化を再実装せず、今回の追加差分はテスト数と実行条件の削減だけにする。

## 確認

Node.js 24.22.1 / pnpm 12.15.0 / Go 1.27.3 / Playwright Chromiumで検証する。

```bash
pnpm --filter @dopagaki/deploy test
pnpm --filter @dopagaki/e2e exec playwright test --list --grep @smoke
pnpm --filter @dopagaki/e2e exec playwright test --grep @smoke --workers=2
pnpm lint:ts
pnpm --filter @dopagaki/e2e typecheck
actionlint .github/workflows/check.yml
pnpm exec prettier --check .
git diff --check
```

CI/配信17件が成功。通常のスモークは2本だけを選択する。全件実行・本番反映は本人の指示で保留している。
