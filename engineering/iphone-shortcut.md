# iPhoneのショートカット連携

YouTubeアプリでShortsを見ているかどうかは、iPhoneでは外から判別できない（他のアプリの画面は読めない。スクリーンタイムの数字もショートカットからは読めない）。そこで、iPhone標準の「ショートカット」アプリのオートメーションで、YouTubeが前面に来た瞬間（開いている）と前面から消えた瞬間（閉じている）をとらえ、相棒の一言を通知で出す。止めたりブロックしたりはしない。

アプリを開く前に一呼吸おかせる介入には、one secの研究がある（Grüning et al., 2023, *PNAS* 120(8)）。DOPAGAKIは一呼吸の先に、本人のWhyと次の一手を見せる。

## 仕組み

| 部分 | 内容 |
|---|---|
| 接続キー | 設定 →「iPhoneのショートカット」で発行する。形式は `<アカウントIDのbase64url>.<64桁の秘密>`。サーバーは秘密のSHA-256だけを保存し、キーは発行直後に一度だけ表示する。再発行すると古いキーは無効、「無効にする」で削除 |
| 開いたとき | `POST /api/shortcut/open`、ヘッダ `Authorization: Shortcut <接続キー>`。返り値は `{title, message, url, stop, minutesLeft}`。message は「今日あとN分。」＋次の課題に触れた相棒の一言（Gemini、失敗時は固定文）。視聴時間が残っていなければ `stop: "yes"` と区切りの一言を返し、ショートカットは url（DOPAGAKI）を開く。YouTubeは裏に下がるだけで止めない。「自分で管理する」「区切りの通知だけ」では残り時間に触れない |
| 閉じたとき | `POST /api/shortcut/close`。直前の「開いた」と組にして使用時間を記録し、「YouTube、N分だったね。次は〜」と返す（固定文。AI利用枠は使わない）。閉じた記録がないまま3時間を超えた「開いた」は数えない |
| 保存 | 開いた時刻と使用時間（開いた〜閉じた）を2週間分（各最大500件）残す。**使用時間は視聴の残り時間から差し引かない**（YouTubeアプリでは普通の動画も見るため）。相棒は本人が振り返りを求めたときだけ回数・時間に触れ、責めない。存在しないアカウントのキーではデータを作らない |
| 上限 | ログイン不要のため、1分あたりアカウントごと10回・全体300回（インスタンスごと）。超えると429 |
| AI利用枠 | 一言は本人のAI利用枠を使う。同じ課題・同じ日なら6時間使い回すので、何度開いても1回分 |

## ショートカットの作り方

配布用のファイルを使う（下記）。手で組む場合は、次の2本を作る。

1. 開いたとき用：「URLの内容を取得」（URL `https://<管理画面のドメイン>/api/shortcut/open`、方法 POST、ヘッダ `Authorization` に `Shortcut <接続キー>`）→「辞書の値を取得」（`message`）→「通知を表示」→「辞書の値を取得」（`stop`）→「もし」`yes` なら「辞書の値を取得」（`url`）→「URLを開く」
2. 閉じたとき用：URL を `/api/shortcut/close` にして、「通知を表示」まで

オートメーションは「新規オートメーション」→「アプリ」（iOSによっては「App」）→ YouTube、「開いている」または「閉じている」、「すぐに実行」→「次へ」→ ショートカットを選ぶ。候補に出ないときは「新規の空のオートメーション」→「アクションを追加」→「ショートカットを実行」で選ぶ。

## 配布用のファイル

`python3 -I scripts/build-shortcut.py` で `dist/shortcut/DOPAGAKI.shortcut`（開いたとき）と `DOPAGAKI-close.shortcut`（閉じたとき）を作り、macOSの `shortcuts sign --mode anyone` で署名する（署名には本番APIのURLだけが入り、接続キーは入らない。署名に含まれるのはAppleの証明書と匿名のIDで、名前やメールアドレスは含まれないことを確認した）。

1. 署名済みファイルをAirDropかiCloud Driveで自分のiPhoneに送り、追加する。追加時に接続キーを聞かれるので貼る
2. 動作を確かめたら、ショートカットの共有 →「iCloudリンクをコピー」で配布用のリンクを作る
3. 受け取った人は、リンクから追加して自分の接続キーを貼り、オートメーション（App → YouTube「開いている」→「すぐに実行」→ DOPAGAKI）を自分で作る。オートメーションはファイルで配れない

## 実機で確かめたこと（2026-11-08）

- 開いたとき用のショートカットを手で実行すると、本番から相棒の一言が通知で届いた
- オートメーション（YouTube「開いている」→「すぐに実行」）で、YouTubeを開いた瞬間に通知が届いた。確認なしで動き、実行の通知はオフにできた
- iOSの表示は「App」ではなく「アプリ」だった。候補にショートカットが出ないことがあり、「新規の空のオートメーション」→「ショートカットを実行」で選べた
