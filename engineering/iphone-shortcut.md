# iPhoneのショートカット連携

YouTubeアプリでShortsを見ているかどうかは、iPhoneでは外から判別できない（他のアプリの画面は読めない）。そこで、iPhone標準の「ショートカット」アプリのオートメーションで「YouTubeを開いた瞬間」をとらえ、相棒の一言を通知で出す。止めたりブロックしたりはしない。

アプリを開く前に一呼吸おかせる介入には、one secの研究がある（Grüning et al., 2023, *PNAS* 120(8)）。DOPAGAKIは一呼吸の先に、本人のWhyと次の一手を見せる。

## 仕組み

| 部分 | 内容 |
|---|---|
| 接続キー | 設定 →「iPhoneのショートカット」で発行する。形式は `<アカウントIDのbase64url>.<64桁の秘密>`。サーバーは秘密のSHA-256だけを保存し、キーは発行直後に一度だけ表示する。再発行すると古いキーは無効、「無効にする」で削除 |
| 開いたとき | `POST /api/shortcut/open`、ヘッダ `Authorization: Shortcut <接続キー>`。開いた時刻を記録するだけで通知しない。返り値は `{openId, action, waitSeconds}`。待つ秒数は「持ち時間を使い切る時刻」と「次の課題を始める時刻（締切から逆算した計画の開始）」の早い方までで、60秒〜15分に収める（60秒は一瞬通っただけの回に反応しないため、15分は実機で待てた長さ）。どちらも無ければ `action: "none"` で待たない |
| 聞き直し | 待ち終わったショートカットが `POST /api/shortcut/check`（`{openId}`）を呼ぶ。閉じた・新しく開き直した・通知済みなら `none`。時刻になっていれば `notify` と相棒の一言（Gemini、失敗時は固定文）を返し、持ち時間を使い切ったときは `openApp: "yes"` でDOPAGAKIも開かせる。待っている間に作業して持ち時間が増えたなどで時刻が後ろにずれていれば `wait` で待ち直させる。同じ回で通知は1回だけ |
| 閉じたとき | `POST /api/shortcut/close`。直前の「開いた」と組にして使用時間を記録するだけで通知しない（204）。閉じた記録がないまま3時間を超えた「開いた」は数えない |
| 保存 | 開いた時刻と使用時間（開いた〜閉じた）を2週間分（各最大500件）残す。**使用時間は視聴の残り時間から差し引かない**（YouTubeアプリでは普通の動画も見るため）。30秒未満で閉じた回は回数・時間に数えない。相棒は本人が振り返りを求めたときだけ回数・時間に触れ、責めない。存在しないアカウントのキーではデータを作らない |
| 上限 | ログイン不要のため、1分あたりアカウントごと10回・全体300回（インスタンスごと）。超えると429。聞き直しは開閉と別に数え、開閉を連打しても通知が抜けない。ショートカットは `notify` のときだけ表示するので、エラーや上限では何も出ない |
| AI利用枠 | 一言は通知するときだけ作り、本人のAI利用枠を使う。同じ課題・同じ日なら6時間使い回す |

## ショートカットの作り方

1. ショートカットアプリ →「オートメーション」→「＋」→「App」
2. App に YouTube、「開いている」を選び、「すぐに実行」にする
3. 新規ショートカットに次のアクションを並べる
   - 「URLの内容を取得」：URL `https://<管理画面のドメイン>/api/shortcut/open`、方法 POST、ヘッダ `Authorization` に `Shortcut <接続キー>`
   - 「辞書の値を取得」：キー `message`
   - 「通知を表示」：本文に取り出した値、タイトルは「DOPAGAKI · 相棒」
4. 任意で、通知の代わりに「URLを開く」（キー `url`）にすると、管理画面の通知プレビューが開く

## 配布用のファイル

`python3 scripts/build-shortcut.py` で `dist/shortcut/DOPAGAKI.shortcut` を作り、macOSの `shortcuts sign --mode anyone` で署名する（署名には本番APIのURLだけが入り、接続キーは入らない。署名に含まれるのはAppleの証明書と匿名のIDで、名前やメールアドレスは含まれないことを確認した）。

1. 署名済みファイルをAirDropかiCloud Driveで自分のiPhoneに送り、追加する。追加時に接続キーを聞かれるので貼る
2. 動作を確かめたら、ショートカットの共有 →「iCloudリンクをコピー」で配布用のリンクを作る
3. 受け取った人は、リンクから追加して自分の接続キーを貼り、オートメーション（App → YouTube「開いている」→「すぐに実行」→ DOPAGAKI）を自分で作る。オートメーションはファイルで配れない
