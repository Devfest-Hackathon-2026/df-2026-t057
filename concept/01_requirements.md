## 1. ペルソナ

### 1.1 主ペルソナ：ユウキ（20歳・大学2年）

- 子どものころから忘れ物と遅刻が多い。課題の時間を毎回短く見積もってしまう
- レポートの前夜に Shorts を2時間見て、提出に遅れる。そのたびに自己嫌悪になる
- スマホを捨てたいわけではない。**やりたいのに、やれない**
- 中学時代に親にスマホを取り上げられ、一人暮らしで初めて自由になって、止め方が分からない
- このままだと遅刻・孤立が重なり、心の不調に進みかねない

### 1.2 副ペルソナ

| ペルソナ | 状況 | このプロダクトの意味 |
|---|---|---|
| 発達特性の診断があり、服薬中の社会人 | 薬で症状は軽くなったが、時間管理の困りごとが残る | 診察で学んだ技法を、日常で練習する |
| 発達特性のある若者 | 次にやることが決まっていれば動きやすい | 予定が画面の中で整理され、次の課題が見える |
| 締切前にだけ困る人 | 普段は大丈夫だが、追い込まれると Shorts に逃げる | 自己制御の個人差は連続しているので、同じ仕組みが役に立つ |

### 1.3 周りの人（将来の利用者）

- **教員**（特別支援学校・一般校）：生活習慣や宿題を、本人が自分で管理できるよう支えたい。家庭の状況が見えれば、面談の質が上がる
- **保護者**：取り上げる以外の方法で、子どもの時間の使い方に関わりたい
- **医師・心理職**：診察と診察の間の様子を、本人と一緒に振り返りたい

| # | 原則 | 根拠 |
|---|---|---|
| P1 | **禁止しない**。視聴は「課題で増える持ち時間」として認める | プレマックの原理、[D](02_evidence.md#d-なぜ禁止ではないのか) |
| P2 | **理由は本人が書く**。AI は決めない | 自己決定理論、[D](02_evidence.md#d-なぜ禁止ではないのか) |
| P3 | **大きな課題は小さな手順に分ける** | アンパッキング効果、認知行動療法、[F](02_evidence.md#f-各原則の根拠) |

| P10 | **閲覧内容は外に出さない** | プライバシー |
| P11 | **画面の中で、次にやることを一つだけ見せる** | 視覚的スケジュールの考え方 |

## 3. 機能要件

### 3.1 MVP（提出までに必要）

| ID | 機能 | 内容 | 原則 |
|---|---|---|---|
| F1 | 課題の登録 | 課題名・締切・本人の見積もり時間を登録する。Google カレンダーや会話（Gemini / Google Chat）からも登録できる | — |
| F2 | **Why の入力** | 登録時に「なぜやるのか」「やらないとどうなるか」を本人が一行で書く | P2 |
| F3 | 手順への分解 | Gemini が課題を具体的な手順と所要時間に分ける。本人が修正できる | P3 |
| F4 | 逆算した予定 | 締切と所要時間から開始時刻を決め、カレンダーに入れる | P4 |
| F5 | 開始の通知 | 開始時刻に知らせる。Shorts を見ているときは動画を止め、画面全体に表示する。**本人の Why と、最初の一手だけ**を大きく出す | P2・P5・P11 |
| F6 | 「閉じる」と「始める」 | 通知から、Shorts を閉じて作業を始めるか、スヌーズするかを選ぶ | P5 |
| F7 | スヌーズと立て直し | 残り時間に合わせて詰め直した予定を出す。変更前後を見て本人が確定する。間に合わない場合は、責めずにそう伝える | P6・P9 |
| F8 | 作業中の表示 | 作業中は静かなタイマーだけにする | — |
| F9 | 持ち時間 | 課題の登録・完了で Shorts の持ち時間が増える。完了は本人が押す | P1 |
| F10 | 記録 | 完了の履歴を草のようなカレンダーで見せる | P7 |

### 3.2 意義を強める機能（MVP の次に優先）

| ID | 機能 | 内容 | 原則 |
|---|---|---|---|
| F11 | **フェーディング** | 予定どおりに始められた日が続くほど、通知を「全画面」→「小さな表示」→「カレンダーだけ」へ弱める。崩れたら一段戻す | P8 |
| F12 | 振り返り | 週ごとに、視聴した分数、スヌーズの回数、予定どおりに始めた割合を見せる。Gemini が責めない言葉でまとめる | P7・P9 |
| F13 | 夜の扱い | 就寝前の時間帯は持ち時間を増やさない、就寝を促す | 睡眠 |

### 3.3 将来の展開（今回は構想として記載のみ）

| ID | 機能 | 内容 |
|---|---|---|
| F14 | 見守りの共有 | 教員・保護者・医療者が、本人の同意のうえで進み具合を見る。本人がいつでも止められる |
| F15 | 生活習慣の課題 | 起床・身支度・持ち物の準備も同じ仕組みで扱う |
| F16 | 間隔をあけた復習 | 間違えた問題を、忘れそうな時期に課題として出す（Anki のような仕組み） |
| F17 | 学びの動画への切り替え | Shorts を閉じるだけでなく、関係する学習動画を提案する |
| F18 | 面談の資料 | 三者面談・診察で、本人と一緒に記録を振り返る画面 |

### 3.4 治療のスキルとの対応

成人 ADHD の認知行動療法で練習するスキルを、どう機能にしたか（詳細は [E](02_evidence.md#e-根拠のある技法成人-adhd-の認知行動療法)）。

| 治療で練習するスキル | プロダクトでの形 | 要件 |
|---|---|---|
| 予定表とやることリストを1つにまとめる | どこから入れても、1つの予定にまとまる | F1、F4 |
| 大きな課題を手順に分ける | Gemini が手順と所要時間に分ける | F3 |
| 優先順位をつけ、いつやるかを決める | 締切から逆算してカレンダーに入れる | F4 |
| 集中できる長さで作業を区切る | 手順ごとの時間に合わせたタイマー | F3、F8 |
| タイマーやアラームで作業に戻る | 開始時刻の通知、Shorts 上の全画面表示 | F5 |
| 気が散ることは後回しにする | 「閉じる」「始める」「スヌーズ」。Shorts は課題のあとに楽しめる | F6、F9 |
| 作業場所から気が散るものを遠ざける | 作業中は静かなタイマーだけ | F8 |
| 最初の一歩から手をつける | 通知には最初の一手だけを出す | F5 |
| 自己否定の考えを置き換える | 責めずに立て直した予定を出す。振り返りも責めない言葉 | F7、F12 |
| うまくいかなかったときの立て直し | 間に合わない場合も、できる範囲の計画を出す | F7 |
| 家族が責めずに支える | 本人の同意のうえでの見守り | F14 |
| 練習を続け、自分の変化を見る | 完了の記録と週ごとの振り返り | F10、F12 |
| 終わってもスキルが残る | 支えを少しずつ減らし、アプリから卒業する | F11 |

**治療にはない、私たちが足したもの**：本人の Why の表示（F2・F5）、Shorts をご褒美として認める（F9）、見る前の一呼吸と「閉じる」（F5・F6）。

## 4. 非機能要件

| 項目 | 要件 |
|---|---|
| プライバシー | 閲覧中の動画の内容・閲覧履歴は AI に送らない、保存しない。保存するのは課題・予定・視聴時間の合計・操作の回数だけ |
| 本人の主導権 | 予定の変更は本人の確認なしに確定しない。記録の共有（F14）は本人の同意制で、いつでも取り消せる |
| 表現 | 責める言葉を使わない。「失敗」ではなく「立て直し」 |
| 規制 | 診断・治療をうたわない（プログラム医療機器に当たらない範囲のセルフケアにとどめる） |
| 安全 | 強い落ち込みや希死念慮をうかがわせる入力があった場合は、相談窓口を案内する（将来） |
| 実行基盤 | Google Cloud（Cloud Run など）で動かす。AI は Gemini |
| アクセシビリティ | 音・動きを控える設定を用意する。色だけに頼らない表示にする |

## 5. 対象外（今回やらないこと）

- 視聴の完全なブロック、強制的な利用制限
- 診断・重症度の判定、治療効果の主張
- 保護者や教員による一方的な監視
- スマホアプリ版（今回はブラウザー上の Shorts が対象）

## 6. 有効性の示し方（採点 3b）

| 段階 | 方法 | 言えること |
|---|---|---|
| 設計の根拠 | 各機能が根拠のある技法に対応していることを示す（2章・3.4） | 「設計の各要素には根拠がある」 |
| 試用 | チーム4人で数日使い、使う前と後を比べる：1日の視聴時間、スヌーズの回数、予定どおりに始めた割合 | 「4人で◯日試して、こう変わった」 |
| 将来 | 精神科医・特別支援学校の教員への聞き取り、より大きな試用 | 今後の課題 |

「設計に根拠がある」ことと「このプロダクトに効果がある」ことは、分けて書く。

## 7. 言葉の使い方

| 使わない | 代わりに |
|---|---|
| 依存症、治療、ADHD を治す | やめられない使い方、意図しない視聴、セルフケア、練習 |
| ADHD の人のためのアプリ | やりたいのに、やれない人のためのアプリ（ADHD は根拠の説明で例として出す） |
| IQ の分布、知的障害の人が一番多い | 実行機能（計画・時間管理・切り替え）の個人差 |
| ドーパミン中毒、脳が壊れる | 目先の楽しさに引かれやすい |
| ショート動画が ADHD を引き起こす | 関連が報告されている（因果は未確定） |
| 禁止の条例は失敗した | 効果は十分に検証されていない |
| YouTube をやめろ | ちょうどいい距離感で、ご褒美として楽しむ |
| ドパガキ（ユーザーや製品を指す言葉として） | 動画のつかみで自分たちを指すときだけ使う |
| 外来で出会った患者、実習で見た症例 | 医学生として、経験のある指導医から教わった一般的な傾向（症例の描写はしない） |
| 認知行動療法と同じ効果がある | 根拠のある技法を取り入れた |
