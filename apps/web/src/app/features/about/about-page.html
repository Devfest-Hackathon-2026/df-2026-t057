禁止ではなく、 距離感を。

DOPAGAKIは、締切から逆算して始める時間を決め、Shortsを見ているその瞬間に「そろそろ、やるか」と知らせるアプリです。 ショート動画を取り上げるのではなく、自分の「なぜ」で手を止め、自分の時間を取り戻す練習の場をつくります。

目的

やめられないのは、意志のせいじゃない

次に見る動画はアルゴリズムが決め、終わりのないフィードは止まる理由をくれません。計画する、時間を見積もる、切り替えるといった力には誰にでも個人差があります。やりたいのにやれないのは、意志ではなく仕組みの問題です。だから、仕組みで支えます。

取り上げるのは、優しさじゃない

スマホを取り上げたり時間を禁止したりしても、自由になった瞬間に止め方を知らないまま放り出されてしまいます。人に決められたルールは、その人がいなくなれば消えます。本人が書いた理由で手を止められるようになることを大切にしています。

最後は、このアプリがいらなくなる

最初はアプリが外から支え、できるようになるほど支えを減らし、最後はアプリがなくても自分で時間を管理できる状態を目指します。

誰のためのアプリか

「言われればやる人」にはいらず、「やる気がない人」は使っても続きません。DOPAGAKIが向き合うのは、その間にいる 「やりたいのに、やれない人」 です。頭の中だけで時間を管理するのは難しくても、画面の中で予定が整理され、次にやることが一つ決まっていれば、動ける人は多いはずです。
